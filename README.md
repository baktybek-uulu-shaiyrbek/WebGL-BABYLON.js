# Фрактал из сфер

Трассировщик лучей на чистом WebGL2, без единой внешней библиотеки.

Фрактал нигде не хранится: узел уровня `l` имеет радиус `R0/2 · 0.5^l` и шесть детей
по осям, кроме направления, откуда пришли. Каждый пиксель сам спускается по этому
неявному дереву, отсекая ветки по точной границе поддерева `3r`. Поэтому память не
зависит от глубины, а стоимость кадра — от числа пикселей, а не от числа сфер
(на 20 уровнях их 143 051 147 460 937).

## Запуск

Откройте `index.html` — сервер не нужен, внешних запросов нет.

## Сборка

Исходники — TypeScript в `src/`. То, что грузит браузер, — `js/`, это вывод
компилятора; **правьте `src/`, а не `js/`**.

```sh
./build.sh        # разовая сборка
./build.sh -w     # пересобирать при каждом изменении
```

Локальный Node не нужен: скрипт поднимает образ с `tsc` в Docker. Первый запуск
собирает образ, дальше сборка мгновенная. При ошибке типов рабочий `js/` не
подменяется (`noEmitOnError`).

Без Docker то же самое делает `npx tsc -p tsconfig.json`.

## Что где

| файл | о чём |
|---|---|
| `src/fractal.ts` | параметры фрактала и обход дерева на CPU (для зума в точку под курсором) |
| `src/shaders.ts` | GLSL: трассировка, освещение, проход показа |
| `src/renderer.ts` | WebGL2, накопление выборок в float-текстуру |
| `src/camera.ts` | орбита, зум в курсор, полёт с клавиатуры |
| `src/ui.ts` | панель |
| `src/main.ts` | сборка и цикл кадров |

## Управление

- перетаскивание — поворот
- колесо — приближение к точке под курсором
- `WASD` или стрелки — полёт

## Картинка

Кадр копится: пока камера стоит, каждый проход добавляет одну выборку со сдвигом
внутри пикселя, поэтому сглаживание, мягкие тени и затенение в складках набираются
сами за секунду-другую. Полоска в панели показывает ход накопления.

Настройки вида собраны наверху файлов: направление и цвет солнца, небо и
коэффициенты освещения — в `src/shaders.ts`, число выборок `maxSamples` — в
`src/renderer.ts`, глубина и палитра уровней — в `src/fractal.ts`.
